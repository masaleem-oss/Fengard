# Security

Fengard sits on the router and controls a whole network, so security reports matter a lot.

## Reporting a vulnerability

Please report it privately through
[GitHub security advisories](https://github.com/masaleem-oss/Fengard/security/advisories/new) rather than a
public issue. Include what's affected, how to reproduce it and the version you tested.

You'll get a reply within a week. Once a fix is out, the advisory is published with credit to you unless
you'd rather stay anonymous.

## Supported versions

Fixes go into the latest release. Please update before reporting.
